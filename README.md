# RIE Bhopal Library Android App

Ready-to-upload Android project for:
https://riebhopallibrary.joomla.com/

## GitHub APK build
Upload the CONTENTS of this folder to the ROOT of a GitHub repository.
Then open Actions -> Build RIE Bhopal Library APK -> Run workflow.
After the green check, download the artifact:
RIE-Bhopal-Library-APK

The APK is a debug build for testing.

## Important
Do not upload the ZIP itself. Extract it first and upload the folders/files inside it.
